# [ADR-0002] vite-plugin-pwa によるモバイル PWA および直前キャッシュによるオフライン閲覧保証（Pragmatic Offline-Read）

* **ステータス**: 承認済（2026-10-03 改定・実態同期）
* **日付**: 2026-09-05（初回承認） / 2026-10-03（ISSUE-030 にて改定）
* **決定者**: MyHomeStock 開発チーム

---

## 1. 文脈と問題提起 (Context)

日常の在庫管理やスーパーでの買い物中、地下食品売り場や大型店舗奥など電波の悪い場所でも買い物リストを素早く確認できる必要があります。また、App Store や Google Play を介さず、誰でも URL から直接スマートフォン（iOS / Android）のホーム画面にインストールできる手軽さが求められました。

一方で、初期検討時に掲げていた「オフラインファースト（地下での更新まで許可）」は、以下の現実的制約と重大なトレードオフに直面しました：
1. **JPA 楽観的排他制御（ADR-0003）との競合**: 家族が別端末で更新した場合、オフライン中に蓄積した更新とのマージ競合（409 Conflict）の解決が極めて複雑化し、データ消失や不整合のリスクが高まる。
2. **Google OAuth2 認証（ADR-0010）とのセキュリティ境界**: 端末ローカルにデータを永続化する際、ログアウト後もデータが残存したり、世帯除外後も見え続けるセキュリティリスクを物理的に防ぐ必要がある。

---

## 2. 決定内容 (Decision)

過剰な「完全オフラインファースト（双方向同期）」のバズワード看板を下ろし、スーパーでの実用性・データ整合性・セキュリティを両立する **「直前キャッシュによるオフライン閲覧保証（Pragmatic Offline-Read）」** を正式採用します：

1. **Web App Manifest の自動生成**:
   - `vite-plugin-pwa` により、アプリアイコン、テーマカラー、スタンドアロン全画面表示定義を自動生成。
2. **静的アセットの Service Worker プリキャッシュ**:
   - HTML, CSS, JS, 画像、フォントを Service Worker でプリキャッシュし、オフライン環境でもアプリシェルの瞬時起動を実現。
3. **PWA インストール誘導バナー**:
   - モバイルブラウザ起動時のホーム画面追加バナー（`beforeinstallprompt`）を提供。
4. **TanStack Query Persister による直前キャッシュ永続化**:
   - `@tanstack/react-query-persist-client` + `@tanstack/query-sync-storage-persister` を導入し、直前に取得した在庫・買い物リストをローカルストレージに永続化（TTL: 24時間）。
5. **セキュリティ 3 大ガードレールの物理強制**:
   - **ガードレール 1（完全物理破棄）**: ユーザーの明示的ログアウト時、およびサーバーからの `HTTP 401 Unauthorized`（セッション失効）検知時に、ローカルストレージ内の全データ（認証プロファイル + クエリキャッシュ）を即座に完全消去（Purge）。
   - **ガードレール 2（時限失効）**: キャッシュの最大保持期間を 24 時間（`AUTH_CACHE_TTL_MS`）に限定し、放置された古いデータの永久残存を防止。
   - **ガードレール 3（機密情報除外）**: セッショントークンや秘密情報はローカルに一切保持せず、画面表示用の DTO のみに限定。
6. **オフライン状態の可視化と更新操作の物理的無効化**:
   - `navigator.onLine` および通信エラー種別の複合判定により、オフライン時は画面上部に「⚠️ オフライン表示中 (最終同期: HH:mm)」バナーを表示。
   - 更新系操作（購入完了、数量変更、1段階消費、新規追加、詳細編集、削除）ボタンを物理的に無効化（Disabled）し、データ競合やサイレントエラーを未然防止。電波復帰時に SWR（Stale-While-Revalidate）で最新実データへ自動同期された段階でボタンを再活性化。

## 3. 結果・影響 (Consequences)

### メリット (Positive)
- **地下スーパーでの確実な閲覧保証**: 電波の届かない地下でも、直前の在庫一覧・買い物リストが体感 0 秒で即座に閲覧可能。
- **データ整合性の完全担保**: オフライン中の更新を制限することで、サーバー側の JPA `@Version` 楽観排他制御を壊さず、家族間での更新重複・先祖返り事故をゼロ化。
- **強固なセキュリティ**: ログアウト時および 401 検知時の物理消去により、Google 認証のセキュリティ境界をクライアント側でも維持。
- **ネイティブアプリ同等の起動体験**: アプリストア審査なしで即日リリースでき、ホーム画面から即座に起動可能。

### デメリット・トレードオフ (Negative / Trade-offs)
- **オフライン中の更新不可**: カゴに入れた商品の購入完了チェックや残量変更は、電波が復帰した地上やレジ付近で行う運用制約が生じる（ただし二重買いやデータ競合リスクの排除とトレードオフ）。
- **iOS Safari の制約**: `beforeinstallprompt` が非対応のため、iOS では共有メニューからのホーム画面追加案内が必要。
