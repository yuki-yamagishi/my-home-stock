# [ADR-0002] vite-plugin-pwa によるモバイル PWA およびオフラインファースト戦略

* **ステータス**: 承認済
* **日付**: 2026-09-05
* **決定者**: MyHomeStock 開発チーム

---

## 1. 文脈と問題提起 (Context)
日常の在庫管理やスーパーでの買い物中、地下や電波の悪い場所でも買い物リストを素早く確認・更新できる必要があります。また、App Store や Google Play を介さず、誰でもURLから直接スマートフォン（iOS / Android）のホーム画面にインストールできる手軽さが求められました。

---

## 2. 決定内容 (Decision)
**vite-plugin-pwa (Workbox)** を採用し、以下を実現します：
1. Web App Manifest（アプリアイコン、テーマカラー、スタンドアロン表示）の自動生成。
2. 静的アセット（HTML, CSS, JS, 画像）の Service Worker 自動プリキャッシュ。
3. アプリ起動時の PWA インストール誘導バナー（`beforeinstallprompt`）の提供。
4. TanStack Query によるクライアントサイドキャッシュ。

---

## 3. 結果・影響 (Consequences)

### メリット
- アプリストア審査なしで即日リリース・即時アップデートが可能。
- ネイティブアプリ同様のフルスクリーン体験と高速起動。
- オフライン環境下でも既存在庫の閲覧が可能。

### デメリット・トレードオフ
- iOS Safari では `beforeinstallprompt` がサポートされていないため、「共有ボタンからホーム画面に追加」のガイド案内が必要。
