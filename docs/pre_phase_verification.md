# 4軸事前検証ログ (Pre-Phase Verification)

本ドキュメントは、機能開発や改修フェーズの着手前に実施する4つの検証軸（①技術的ボトルネック, ②UX・エッジケース, ③データ永続性・互換性, ④テスト自律性）の評価記録です。

---

## 1. 事前検証 概要
* **対象プロジェクト**: MyHomeStock (Spring Boot 3 + React PWA + PostgreSQL 16)
* **実施日時**: 2026-09-05
* **検証対象**: 初期開発ハーネスおよびベースラインアーキテクチャ

---

## 2. 4軸検証項目と評価結果

### ① 技術的ボトルネック検証（技術）
- **Java 21 / Spring Boot 3**: LTS バージョンによる仮想スレッド対応と Jakarta EE 10 標準準拠を確認。
- **OpenAPI 型同期**: SpringDoc が生成するスキーマと `openapi-typescript` の連携により、手作業での型二重定義を完全排除。
- **ビルド・コンパイル**: Maven Wrapper (`mvnw.cmd`) による Java 21+ での自動ビルドと、Vite による秒速 HMR を確認。

### ② UX・エッジケース検証（UX）
- **PWA モバイル対応**: スマートフォン（iOS Safari / Android Chrome）でのホーム画面追加プロンプト（`beforeinstallprompt`）とオフライン動作を設計。
- **同時操作時の競合**: 夫婦や家族間での在庫同時更新に対し、楽観的排他制御エラー（409 Conflict）をユーザーフレンドリーに通知し、自動再取得するフローを確立。
- **検索・フィルタリング**: 大量アイテム登録時でもクライアント側で即座に絞り込み可能な UI を構築。

### ③ データ永続性と互換性検証（永続性）
- **PostgreSQL 16**: ACID 特性を担保し、Flyway による SQL バージョン管理 (`V1__init_schema.sql`) で安全なスキーマ進化を保証。
- **楽観的排他制御 (`@Version`)**: JPA による `version` カラムの自動インクリメントと更新競合検知を `StockItemRepositoryTest` にて検証完了。
- **監査カラム**: `created_at`, `updated_at` の自動タイムスタンプ付与を確認。

### ④ テスト自律性と品質ゲート検証（テスト）
- **単体テスト容易性**: 純粋ビジネスロジック層（`frontend/src/core/`）を UI から分離し、Vitest で高速 100% カバレッジ達成。
- **バックエンドテスト**: H2 インメモリ DB による `@DataJpaTest` および `@WebMvcTest` により、Docker 起動を待たずに単体・リポジトリテストが瞬時に実行可能。
- **ワンショット品質ゲート**: `npm run check` により、シークレットスキャン、ドキュメント完全性、型検査、テスト、ビルドの一括パスを確認可能。
