## 1. 解決すべき課題・背景 (Why / Background)

スマートフォン（PWA / モバイルブラウザ）での利用時において、以下の2点の深刻なUX・レイアウト課題が存在していた：

1. **ヘッダー要素のオーバーフロー・見切れ**:
   - デスクトップ向けの横並びレイアウト（「ブランドアイコン＋MyHomeStock＋稼働ステータス」「3タブナビゲーション」「世帯管理ボタン＋アバター＋ログアウト」）が幅 375px 前後のスマホ画面で約 450px 以上を要求し、右端のユーザーアバターやログアウトボタンが画面外に見切れて操作不能になっていた。
   - また、ログイン後の日常利用において、貴重なヘッダー領域に大きなアプリアイコンと「MyHomeStock」の文字が常時占有されているのはスペース効率が悪かった。

2. **在庫クイック追加フォームの常時表示による一覧性の著しい悪化**:
   - メトリックカード直下に配置された巨大なクイック追加フォームがスマートフォンの縦画面の大半を占有していた。
   - 本来最も閲覧・操作頻度が高い「在庫アイテム一覧」や「買い物リスト」を見るために毎回大量のスクロールを強いられ、使い勝手が悪化していた。

本改修では、これらの課題を根本から解決し、スマートフォンでストレスなく快適に利用できる洗練されたモバイルファーストUXを実現する。

---

## 2. 排除するリスク (Risks to Eliminate)

1. **モバイル／デスクトップ間の操作性トレードオフ・二重管理リスクの排除**:
   - モバイル向け最適化によってPC・タブレットの大画面表示での一覧性や操作性を損なわないこと。Tailwind のレスポンシブ（`sm:` 境界）により、単一のコードベースで両環境に最適なレイアウトを提供する。
2. **在庫追加導線の見失いリスクの排除**:
   - フォームをポップアップ（モーダル）化したことで追加方法が分からなくなることを防ぐため、一覧上部の明示的なボタンに加え、スマートフォンでは親指で常にタップできる固定フローティングアクションボタン（FAB: `+`）を常時配備する。
3. **既存の在庫管理仕様（個数管理・4段階残量管理）のデグレード排除**:
   - ISSUE-010 で実装された4段階残量管理（十分・まだまだ・怪しい・すっからかん）と個数管理の切り替え、バリデーション、単位設定、期限クリア機能、メモ入力、楽観的排他制御の連動ロジックを100%忠実にモーダルへ継承する。

---

## 3. 要件定義 (Requirements)

1. **ヘッダーのスマートフォン最適化**:
   - モバイル表示時（`< sm`）:
     - アプリアイコンおよび「MyHomeStock」テキスト、API接続テキストを非表示（または極小ロゴ化）。
     - 左端に世帯名（`user.householdName`）をすっきりと配置。
     - ナビゲーションタブ（在庫・買い物・期限）はヘッダーからは非表示とし、ボトムナビゲーションバーに移行。
     - 右端に「世帯管理（アイコンボタン）」「ユーザーアバター」「ログアウト（アイコンボタン）」を配置し、360px の最小画面幅でも絶対に見切れないようにする。
   - デスクトップ表示時（`sm:` 以上）:
     - 従来のブランドロゴ、中央のナビゲーションタブ、右側の世帯管理・アバター・ログアウトが横並びで配置されるレイアウトを維持。
2. **モバイル専用ボトムナビゲーションバーの導入**:
   - モバイル表示時（`< sm`）のみ画面最下部に固定表示（`fixed bottom-0`）。
   - 「在庫」「買い物（不足品件数バッジ付き）」「期限（期限間近件数バッジ付き）」の3タブを親指でタップしやすいサイズで配備。
   - コンテンツ下部にパディング（`pb-24`）を確保し、ナビやFABによって一覧コンテンツが隠れないようにする。
3. **在庫追加のモーダル（ポップアップ）化 & FAB配備**:
   - 画面上部の常時表示フォームを撤去し、`frontend/src/components/stock/CreateStockModal.tsx` として独立したモーダル（ポップアップ）を実装。
   - 個数管理 / 4段階残量管理の切り替え、バリデーション、各入力項目を完全移植。
   - 呼び出しトリガー：
     - 在庫一覧・買い物リスト上部の「+ 在庫を追加」ボタン。
     - スマートフォン表示時（`< sm`）の画面右下フローティングアクションボタン（FAB: `+`）。

- [x] デスクトップ表示（幅 1024px 以上）では従来のヘッダー配置（ブランド＋中央タブ＋右側ユーザー操作）が維持され、ボトムナビおよびFABが非表示になること
